## Интерфейс и доступность

Проверены `ProductImportDialog`, его открытие со страницы товаров и общий `BaseDialog` по правилам `docs/UI_DESIGN_REVIEW.md`. Используются существующие компоненты и токены TailAdmin Vue.

- При ширинах 320, 640, 768, 1024 и 1280 px окно и страница не выходят за границы viewport. Ширина окна соответственно 288, 608, 736, 992 и 1024 px. Длинные русские названия товаров, причины ошибок и имя файла переносятся; содержимое окна доступно вертикальной прокруткой.
- Визуально проверены исходное состояние, выбор файла, неактивные элементы, загрузка категорий, отсутствие категорий, ошибка получения категорий, ошибка загрузки файла, успешный результат, частичный успех с ошибками строк и заглушка вкладки изображений.
- Проверены переключение вкладок стрелками, сохранение выбранного файла при переключении вкладок и повторном открытии, восемь последовательных нажатий Tab во время загрузки, закрытие Escape и получение результата после повторного открытия. Escape сначала закрывает открытый список категорий, затем окно; фокус возвращается на кнопку открытия.
- Axe не обнаружил serious/critical нарушений в состояниях empty, category-error, loading, upload-error и success. Правило `color-contrast` отключено, как в существующем каталожном E2E-наборе; это не является полной сертификацией доступности.

Найденные и исправленные замечания:

1. Общий `BaseDialog` учитывал кнопки внутри отключённого `fieldset` и элементы с `tabindex=-1` при определении границ фокуса. Добавлена фильтрация реально доступных и видимых элементов. При отключении текущей кнопки загрузки фокус переносится на вкладку товаров.
2. После переключения вкладки или закрытия окна нативный file input показывал отсутствие файла, хотя выбранный `File` сохранялся. Видимая кнопка теперь отображает имя из состояния; панели вкладок сохраняются через `v-show`.

Оба исправления повторно проверены в Chromium.
