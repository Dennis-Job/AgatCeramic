# Счётчики очередей заказов — 2026-11-05

Вкладки «Новые», «В работе» и «В доставке» показывают реальные числа, включая
ноль, по образцу обращений. На мобильном экране значения есть в выборе статуса.
Счётчики относятся ко всей текущей очереди: поиск, оплата, сотрудник, пагинация
и месяц статистики на них не влияют. После сохранения статуса они обновляются.
«В работе» объединяет активные нетерминальные этапы, кроме new/shipped,
включая пользовательские этапы. При ошибке неизвестные значения скрываются;
повторная загрузка доступна отдельно и не блокирует список.

## Изменения

- Backend: OrderQuery, OrderController, admin routes и OrderStatusCountsTest.
  Новый GET `/admin/order-status-counts`, доступ `orders.view`, один агрегатный
  запрос без загрузки клиентских данных. Миграции не нужны.
- Admin: тип и сервис counts, useOrderStatusCounts, useOrdersWorkspace,
  OrdersWorkspace и семантический tone рабочей очереди. Защита поздних ответов
  и отписка при закрытии; используются существующие UiBadge и цвета.
- API.md, openapi.json и OPENAPI_MIGRATION_PLAN.md: контракт v17.1.
- Unit/E2E, фикстуры и восемь проверенных Windows/Linux эталонов заказов.
