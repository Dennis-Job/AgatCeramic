# TASK-A090: тултипы только на нужных действиях

Дата: 2026-10-04

## Изменения

- У `UiButton` больше нет автоматического тултипа по `aria-label`; его нужно
  включить явно через `tooltip`.
- Тултипы оставлены для копирования товара, настройки характеристик,
  редактирования и удаления строк товаров/категорий, а также добавления и
  редактирования фото из таблицы товаров.
- Удалены подсказки с кнопок закрытия, очистки, календаря, выбора группы,
  сортировки и элементов оболочки админки.
- Подсказка открывается только после движения указателя, не показывается по
  клавиатурному фокусу. Активация, Escape, прокрутка и размонтирование скрывают
  её. Короткий переход на сам tooltip оставляет его доступным для чтения.
- Обновлены UI Kit и тестовые ожидания для tooltip, уведомлений, диалогов и
  навигации.
