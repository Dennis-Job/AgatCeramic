# Выпадающие категории каталога

**Goal:** показывать дочерние категории внутри выпадающего списка родителя автоматически по `parent_id` из API.

**Architecture:** сохранить существующее дерево `buildCategoryTree` и мобильный drawer. В горизонтальном меню выводить корни; родитель — кнопка раскрытия, листья — ссылки. Общий UI dropdown использует native popover, существующие tokens и motion. Внутри — ссылка на все товары родителя и рекурсивный список потомков. Прямые ссылки сохраняют существующий контракт фильтрации и брендовый scope.

**Tech Stack:** Nuxt 4, Vue 3, TypeScript, Playwright.

**Scope:** `/catalog`, `/brand/*` и сохранённый preview через общий CatalogCategories. Без миграций, изменения API, ручных списков категорий, зависимостей и коммита. Существующие незакоммиченные изменения сохранить.

## Решения и проверки

Верхний уровень содержит только корни. Все потомки видны внутри одного прокручиваемого dropdown с визуальной вложенностью: это сохраняет доступ ко всем уровням без каскада боковых окон. Общие цвета, 13 px и цели 44 px сохраняются. Кнопка родителя только раскрывает; переход к родителю находится внутри списка. На мобильных сохраняется текущий draft до «Применить».

Проверить особенно: dropdown не обрезается scroll-контейнером sticky; активна ветка выбранного потомка; короткий viewport прокручивает список; при скрытии навигации dropdown закрывается; сброс page/attributes/collection и сохранение остальных фильтров не меняются.
