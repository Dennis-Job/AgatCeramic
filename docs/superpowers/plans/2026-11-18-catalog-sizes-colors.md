# Размеры и цвета в фильтрах

Запрос владельца: все фактические размеры из характеристик товаров выводить
списком выбора, цвета — кружками в ряд по сохранённым кодам.

Текущие данные: `razmer` — string, значения хранятся у товаров;
`tsvet` — select с HEX-кодом в `options.value`, названием в `options.label`.
Хранение цветов, Admin и товарные данные менять не требуется.

- [x] Backend: distinct строковые размеры в options для `razmer`; точный OR
  по `values`, старые ссылки `text` работают. Назначение категории и
  `is_filterable` сохраняются, только публичные товары, до пагинации.
- [x] Client: размеры checkbox-списком; общий UiColorSwatch с native checkbox,
  доступным названием, title, focus/checked/disabled, touch 44 px; flex-wrap.
  Использовать только валидный HEX, неизвестные старые коды показывать текстом
  без угадывания цвета. Draft/Apply, chips/reset/history сохраняются.
- [x] Тесты поведения, typecheck/build/format, API/PG, пять ширин и независимый
  UI Guard по свежим screenshot-артефактам. Обновить API/UI-kit/DONE.

Без миграций и коммита. Несвязанные текущие изменения сохраняются.
