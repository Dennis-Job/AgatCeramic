# Контакты в нижней части бокового меню

Запрос: повторить композицию `.sm-foot` из exampleSite.html — телефон сайта,
почта, редактируемый текст, ниже строка текстовых ссылок соцсетей.

Решение: StorefrontHeader уже загружает site-settings для верхней полосы;
он передаёт в SiteHeader готовые телефон/email через props, без запросов из
shared UI. Соцсети берутся из существующего footer.social_links. Текст получает
отдельное header.menu_note (до 1000 символов), редактируемое в новой UiCard
«Боковое меню» в настройках шапки. Отсутствующее старое значение наследует
footer.tagline; явно пустое скрывается. Телефон использует существующую общую
нормализацию/маску и канонический tel. Пустые контакты/соцсети скрываются.

Панель сохраняет текущую навигацию, поиск, focus trap, Escape, scroll lock и
анимацию. Низ меню — колонка с gap8, контакты13px, текст12px, соцсети11px
uppercase/letter spacing и тонкая нижняя линия, как референс. Много соцсетей
переносятся, длинный текст не расширяет панель. При коротком окне прокручивается
вся панель. Цвета/tokens не меняются. Публичный сайт и preview используют один UI.

- [x] Backend: совместимый header.menu_note, сохранение/публикация/permissions,
  tests и контракт. Поручено отдельному агенту; frontend ему не принадлежит.
- [x] Admin: поле UiTextarea с лимитом1000, нормализация старых ответов,
  подсказка источников контактов/соцсетей, save/reload/publish/empty checks.
- [x] Client: готовые props контактов и соцсетей, нижний блок SiteHeader,
  единый mapping для public/preview; тесты реальных значений, пустых данных,
  длинных строк/12 ссылок, короткого viewport, keyboard/reduced motion.
- [x] Проверки: unit/lint/format/typecheck/build, релевантные и полный Client
  E2E, независимый UI Design Guard, обновление UI-kit/UX/task/report.

Риски проверки: фиктивные контакты референса не попадают в продукт; отсутствующий
menu_note отличается от явно пустого; неисправный номер не создаёт tel другой
страны; social URL проходят safeLink; последний social link участвует в focus
trap; при ошибке сохранения ввод не теряется. Коммит не запрошен.
