# Страница уведомлений

**Goal:** заменить окно колокольчика отдельной страницей новых заказов и обращений.

**Architecture:** Vue Router `/notifications`, feature workspace и существующий
`useAdminNotifications`; один экземпляр состояния принадлежит AdminLayout и
доступен шапке и странице через provide/inject. Backend и API не меняются.

**Spec:** запрос владельца от 2026-10-26: слева «Заказы»/«Обращения», справа
список новых уведомлений. На мобильном навигация располагается сверху.
Сохраняются Seller tokens, permissions и правило исчезновения после смены статуса.
