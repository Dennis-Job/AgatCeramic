# Компактные списки и выравнивание карточек

**Запрос:** замечания владельца к `/catalog` от 2026-11-18.

**Решение:** общий UiSelect высотой не менее 44 px, шрифт 13 px,
без нативной стрелки и внешней рамки при клике. Панель вариантов использует
существующий светлый `--color-bg-soft`, тонкую границу, мягкую тень и общий
motion `ui-submenu-popover` (0.35 s). Семантика select-only combobox,
клавиатура, Escape, Tab, поиск по буквам, disabled и reduced motion сохраняются.
Popover располагается в top layer, чтобы работать внутри мобильного drawer.
Сортировка занимает до 230 px на desktop, на телефоне — доступную ширину.

Карточки используют общие строки CSS subgrid в каждом ряду: фото, бренд,
полное название, категория/размер, цена. Без ограничения длины названия и
измерений DOM; компактный вариант row сохраняется.
