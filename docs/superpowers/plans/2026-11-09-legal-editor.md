# Визуальный редактор юридических документов

Цель: ровная колонка статусов и минимальный WYSIWYG с заголовками, жирным,
курсивом, списками, ссылками и выравниванием left/right/justify.
Выбор визуального ввода и выравнивания подтверждён пользователем в чате.

Сохраняем `body` как текст; добавляем nullable `content` со структурированным
документом. Старые версии не изменяются. Backend проверяет разрешённую схему
и получает текст из неё. Публичный SSR выводит только разрешённые Vue-элементы.
HTML из документа не исполняется. Публикация остаётся отдельным действием.

- [x] Backend: migration, validation, derived body, resource, contract tests/docs.
- [x] Admin: UiRichTextEditor на Tiptap, toolbar, состояния, preview и grid списка.
- [x] Client: SSR renderer, plain fallback, безопасные ссылки и alignment.
- [x] Проверки: unit, lint/format/build, E2E/axe и пять ширин.
- [x] Независимый UI Design Guard, итоговый diff и статус задачи.

Backend делегирован отдельно от frontend. Никаких commit/push или публикации
юридических документов в рамках этой задачи.
