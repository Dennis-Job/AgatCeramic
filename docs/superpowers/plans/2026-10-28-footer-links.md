# Настраиваемые ссылки подвала

Запрос владельца: самостоятельно задавать навигацию подвала, добавить колонку
«Мы в соцсетях» по exampleSite.html и ссылку к тексту справа в нижней строке.

Решение: расширить существующее общее оформление, сохранить UiCard/UiField/UiInput,
типографику и палитру Client. Три плоских списка ссылок (навигация до 256,
«Исследовать» до 12, соцсети до 12) используют один редактор с добавлением,
удалением и перемещением. Пустые колонки скрываются. Нижняя строка получает
необязательный URL: без него остаётся обычным текстом. HTML не исполняется.
Соцсети не заполняются выдуманными адресами из референса.

Автоматическое копирование шапки при каждом рендере не даёт самостоятельной
настройки. Поэтому существующие данные без navigation_links читаются как прежняя
плоская навигация, а явно сохранённый список (включая []) становится независимым.
Миграция БД не требуется. Сохранение и публикация остаются раздельными.
