# Редактирование черновика юридического документа

Цель: реализовать одобренное владельцем действие «Редактировать»: сохранить
исправления в тот же черновик, оставив опубликованные версии неизменяемыми.
Исполнение — в текущем workspace, без commit. API и UI проверяются независимо.

- [x] Backend: regression RED → PATCH с settings.manage, общей проверкой rich
  content и уникальности версии, transaction/row lock против одновременной
  публикации, аудит обновления. API.md/OpenAPI обновить вместе с контрактом.
- [x] Admin: regression RED → действия в строке и preview, загрузка существующей
  версии в общий редактор, «Сохранить изменения»/«Отменить редактирование».
  Тип фиксируется. Временный ввод новой версии сохраняется при входе в edit;
  ошибка не очищает edit. Сохранение не публикует и не создаёт новую запись.
- [x] Проверка: unit, settings E2E (rich/plain, ошибки, отмена, публикация),
  пять ширин/axe, lint/format/build, backend PHPUnit/Pint/PHPStan/architecture
  и релевантный PostgreSQL-прогон; независимый UI Design Guard и code review.
  Обновить отчёт и DONE; миграции не требуются.
