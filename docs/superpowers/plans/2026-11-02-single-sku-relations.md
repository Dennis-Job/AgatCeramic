# Добавление связей по одному SKU

**Цель:** одно поле SKU → найденный товар → «В сопутствующие» или
«В рекомендуемые». После добавления поле очищается и получает фокус.

**Границы:** Vue feature-компонент и существующий composable; общий UI-kit,
API URL/schema, права и ограничения связей сохраняются. Точный SKU получает
приоритет в существующем серверном поиске. Данные текущего магазина при QA
не сохранять. Предыдущие незакоммиченные изменения сохранить, commit не делать.

  удаление и повторное добавление, защита начальной загрузки.
