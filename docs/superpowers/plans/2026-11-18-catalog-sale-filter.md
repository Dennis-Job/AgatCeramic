# Фильтр «Распродажа»

Запрос владельца: добавить checkbox «Распродажа» рядом с «В наличии».
Используется существующий признак товара `is_on_sale`, тот же, что у бейджа.
Общий `UiCheckbox size="compact"` располагается сразу после «В наличии» в
общей форме каталога, бренда и preview; новые стили не нужны.

План:

- [x] Backend: regression-тесты, optional boolean `is_on_sale` у публичного
  каталога, фильтрация выдачи при `1`, OpenAPI. `0` не ограничивает выдачу;
  фильтр сочетается с остальными и не меняет навигацию/варианты фильтров.
- [x] Client: URL → draft → Apply, checkbox, chip «Распродажа», удаление,
  сброс и история; мобильное закрытие отменяет draft как прежде.
- [x] Проверить API и frontend E2E, typecheck/build/format, пять ширин,
  keyboard/SSR и независимый UI Design Guard; обновить документы и DONE.

Миграции и изменения админки не требуются. Существующие незакоммиченные
изменения компактных controls сохраняются; коммит не создаётся.
