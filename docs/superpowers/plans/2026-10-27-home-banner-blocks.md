# Independent homepage banners implementation plan

**Goal:** Разделить контент блоков главной и переименовать их в «Сетка баннеров»
(`categories`) и «Меню баннеров» (`materials`).

**Architecture:** Технические типы сохраняются. Меню получает собственный
`materials.items` той же структуры, что `categories.items`. Разовая миграция
копирует прежний контент в отсутствующий список отдельно в черновиках и
публикациях. После миграции между списками нет fallback или синхронизации.
Пустой список меню допустим. Существующие стили и URL-якоря сохраняются.

**Tech Stack:** Laravel/PostgreSQL, Vue Admin, Nuxt Client.

## Global constraints

- Существующие изменения рабочей копии сохранить; commit не создавать.
- Не заменять опубликованный контент черновиками и не публиковать изменения.
- Уже существующий `materials.items`, включая пустой список, сохранять.
- Изображения/nullable URL, permissions и pending/uploading guards сохранять.
- Новые ссылки, новые виды баннеров и визуальный редизайн не входят в задачу.

## Tasks

- [x] Backend: регрессионные тесты независимого сохранения/публикации,
      валидация собственного списка, миграция старых снимков, media references,
      defaults и OpenAPI. Проверить повторный запуск и PostgreSQL.
- [x] Admin: тесты редактирования двух независимых списков, переименование,
      общий редактор элементов без дублирования UI и сохранение guard-сценариев.
- [x] Client: тест разных данных grid/menu и самостоятельного меню,
      независимый mapping/SSR/preview, локальное переключение вкладок меню.
- [x] Проверить тесты, типы, сборки и форматирование затронутых приложений.
- [x] Независимый UI Design Guard; документация и статус задачи; финальный diff.

## Review focus

Пустое/отключённое меню; меню без сетки; одинаковые id в разных списках;
отдельные опубликованный snapshot и черновик; удаление медиа, которое остаётся
только в меню; выбранные upload-файлы при перестановке баннеров.
