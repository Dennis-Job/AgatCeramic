# Категории: навигация слева, сведения справа

2026-10-15. По указанию владельца применён утверждённый паттерн страницы
характеристик. На desktop категории находятся слева, подробная информация и
назначенные характеристики — справа. На узких экранах выбор категории
расположен над содержимым.

## Поведение

- Левая навигация сохраняет иерархию категорий, показывает slug и количество
  назначенных характеристик. Поиск по названию/slug оставляет родительский
  контекст найденных узлов.
- Выбор категории показывает только её сведения. «Все категории» возвращает
  полный подробный список. Ссылки на родителя и подкатегории переключают
  выбор и фокусируют соответствующий блок.
- Выбор и поиск сохраняются в query `category`/`search`. После ошибки загрузки
  выбранная категория сохраняется до успешного повтора; после удаления
  выбранной категории открывается общий список.
- Существующие формы создания, редактирования, назначения характеристик,
  удаления и подробностей сохранены. API, permissions и данные не менялись;
  миграции не требуются.

## Реализация

Общая компоновка `CatalogReferenceLayout` извлечена из страницы характеристик
и используется обоими справочниками. Она отвечает только за сетку и отступы.
Навигация категорий находится в feature-компоненте `CategoriesNavigation`,
вычисления дерева/поиска/счётчиков — в `useCategoryNavigation`.

Изменённые исходники:

- `frontend/admin/src/components/shared/CatalogReferenceLayout.vue` и `UI_KIT.md`;
- `features/categories/components/CategoriesWorkspace.vue`, `CategoriesList.vue`,
  `CategoriesNavigation.vue`;
- `features/categories/composables/useCategoryNavigation.ts` и
  `features/categories/types/category.types.ts`;
- `features/attributes/components/AttributesWorkspace.vue` — подключение общего layout.

Пути feature-файлов приведены относительно `frontend/admin/src/`.
Тесты: `tests/categoryNavigation.test.ts`, `tests/categoryOverview.test.ts`,
`e2e/categoriesWorkspace.spec.ts`, `e2e/categoryOverview.spec.ts`, а также
селекторы в `e2e/catalog.spec.ts` и `e2e/actionTooltips.spec.ts`.
В `e2e/headerPopovers.spec.ts` исправлено устаревшее ожидание трёх колонок
меню «Товары»: после предыдущего согласованного переноса ссылки их две.

## Проверка

ESLint, Prettier и production build проходят. Unit: 148/148. Целевые
production E2E: 58/58 — 21 workspace-сценарий, 23 сценария существующих действий
категорий и 14 регрессионных сценариев характеристик. Проверены 320/640/768/
1024/1280/1440 px, длинные строки, отсутствие overflow, axe, клавиатура,
URL/reload, loading/error/empty и формы.

При проверке обнаружен и исправлен overflow длинного выбранного названия на
320/640/768 px: общий grid использует `minmax(0, 1fr)` и сжимаемый мобильный slot.
Первый запуск unit остановился на Windows sandbox EPERM в системном temp до
выполнения тестов; повтор с repo-local TEMP/TMP прошёл полностью.

Независимый UI Design Guard принял исходники и desktop/mobile снимки, включая
длинный контент, empty/error; открытых P0–P2 замечаний нет. Утверждённая палитра
сохранена. Визуальные evidence находятся в локальном `.tmp/categories-workspace-*`.

Полный Windows production-прогон: 578/592 прошли с первой попытки. Из 14
расхождений четыре — намеренное изменение snapshots категорий; независимый
Guard просмотрел и одобрил ровно четыре новых Windows эталона (default,
loading, empty, error). Два теста обновлены под новые селекторы. Ещё один
сохранял устаревшее ожидание трёх колонок меню «Товары». Два случая
`ERR_NO_BUFFER_SPACE` при параллельном прогоне успешно перепроверены одним
worker без изменения исходников.

После обновления эталонов/селекторов контрольный прогон 65/65 прошёл, включая
baseline/responsive категорий, baseline характеристик/групп, tooltip и меню.
Отдельная повторная проверка combine route — 1/1 PASS. Неустранёнными остаются
только пять ранее известных product snapshots с прежней кнопкой «Скачать Excel»;
они не относятся к категориям и не заменялись. Linux/macOS эталоны в этой
Windows-сессии не обновлялись.

Воспроизводимые локальные JSON-результаты:
`frontend/admin/.tmp/categories-full-regression.json`,
`categories-final-regression.json`, `categories-combine-recheck.json` (последние
два в том же каталоге). Build сохраняет существующее предупреждение о chunk
больше 500 kB.

Локальная Docker-админка перезапущена для обновления Vite cache; в браузере
проверена реальная страница `/categories?category=27`: слева выбран
«Керамогранит», справа отображаются только его сведения и 13 характеристик.
