# Настройки сайта в Admin

На `/settings` три секции владеют независимыми формами. Каждая формирует
запрос в своём composable и обновляет свои данные после ответа API.

| Секция | Composable | Ответственность |
| --- | --- | --- |
| `SellerDetailsSection.vue` | `useSellerDetails.ts` | Реквизиты, контакты, явный выбор одного сохранённого телефона и переключатель публичности банковских данных. |
| `LegalDocumentsSection.vue` | `useLegalDocuments.ts` | Создание и правка черновиков, предпросмотр, публикация. При выходе из правки восстанавливается начатая форма новой версии. |
| `ComplianceApprovalsSection.vue` | `useComplianceApprovals.ts` | Журнал и запись решения по выбранной версии политики ПДн с правом `settings.approve`. |

`SettingsWorkspace.vue` собирает секции, показывает загрузку и уведомления.
`useSettingsWorkspace.ts` параллельно загружает данные, блокирует повторные
и параллельные отправки и передаёт в согласования только опубликованные
версии политики. Запись журнала открывает общий предпросмотр по ID документа.
Подписи и варианты выбора хранятся в `settingsOptions.ts`, типы действий —
в `types/settings.types.ts`.

Ошибка оставляет введённые значения. Успешная отправка обновляет только свою
форму. Сервер проверяет права, публичность банковских реквизитов и допустимость
выбранной версии. Контракты запросов описаны в [API.md](API.md#реквизиты-и-юридические-документы).
