# Загрузка объединений после сохранения шаблона в Excel

Дата: 2026-10-07.

## Причина ошибки

Заполненный `product-groups-template.xlsx` отклонялся с сообщением
«Лист „Группы“: не изменяйте заголовки шаблона». У операции импорта №10
в локальной базе статус `failed`, число прочитанных строк — 0.

Все 25 заголовков A1:Y1 соответствовали шаблону. Excel сохранил также пустую
Z1 над скрытым справочником осей; OpenSpout возвращал 26 значений, и сравнение
со списком из 25 заголовков ошибочно отклоняло файл.

## Проверка исходного файла

- Лист «Группы», строка 4: `Создать`, ключ и код `1234567`, пустой исходный
  код, название «Раковины цвета», ось «Цвет».
- Лист «Состав», строки 6–9: SKU `6000030`, `6000031`, `6000032`, `6000033`.
- Все четыре SKU существуют; категория 34, бренд 8; значения цвета различаются.
- Исходный файл прочитан исправленным reader. Planner и реальный `applyBulk`
  прошли на текущем PostgreSQL внутри транзакции с обязательным rollback.
  Все инварианты состава и общих характеристик прошли; группа после отката
  отсутствует. Рабочее объединение не создавалось, исходный XLSX не изменялся.

## Исправление

Reader удаляет только пустые ячейки в конце строки заголовков перед строгим
сравнением. Изменённые названия, пропущенные/переставленные колонки и непустые
дополнительные заголовки по-прежнему отклоняются. Строки скрытого справочника
осей по-прежнему не считаются данными группы.

Добавлены регрессионные сценарии: загрузка файла с пустыми хвостовыми
заголовками, числовыми ключом/кодом и четырьмя числовыми SKU; выполнение
реальной job, проверка HTTP-статуса и сохранённого состава. Отрицательный
сценарий проверяет конкретную ошибку изменённого заголовка в заполненном файле.

Локальный worker очереди перезапущен для загрузки исправленного класса.
Повторно можно загрузить тот же файл.

- `composer test`: 372 tests passed.

  предварительно guard подтвердил отдельную `agatceramic_feature_test`.

  passed. Architecture guard не нашёл блокирующих нарушений; прежние замечания
  размера/сложности классов остаются advisory.
- `composer analyse`: no errors. Первичный запуск был ограничен sandbox
  при открытии локального сокета PHPStan; повторная проверка прошла.
- `composer audit --locked`: no security vulnerability advisories found.
  Проверка выполнена с доступом к Packagist после ограничения DNS в sandbox.
- Независимое code review: блокирующих замечаний нет; отрицательный тест
  усилен по замечанию reviewer.
