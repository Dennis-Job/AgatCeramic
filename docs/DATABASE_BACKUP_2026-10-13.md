# Локальный бэкап тестовых баз — 2026-10-13

По запросу владельца перед очисткой Docker создана резервная копия всех пяти
баз PostgreSQL проекта, кроме системных шаблонов, включая основную `agatceramic`.
Владелец подтвердил, что данные тестовые, и прямо запросил обычную копию
без шифрования. Это локальное исключение для разработки; production-процедура
из `DATABASE_BACKUP_RESTORE.md` не менялась.

Копии в формате PostgreSQL custom (`pg_dump --no-owner --no-privileges`)
хранятся вне репозитория, на диске Windows. Рядом сохранены инструкция,
manifest, SHA-256, скрипт восстановления и результат проверки. Содержимое
дампов, контрольные суммы и секреты в Git не добавлялись. Redis, `.env`,
ключ Laravel и медиафайлы в бэкап не включены; существующие файлы проекта
на Windows необходимо сохранить для дальнейшей работы.

## Проверка

- PostgreSQL 17.9; пять дампов суммарно 801 083 байта.
- Комплектный скрипт восстановления выполнен в отдельном PostgreSQL-контейнере
  без сети, с временным хранилищем в tmpfs.
- Все пять баз восстановлены через `pg_restore --single-transaction
  --exit-on-error --no-owner --no-privileges`.
- Число строк совпало во всех 470 пользовательских таблицах.
- SHA-256 всех пяти архивов повторно проверен после восстановления.
- Скрипт предварительно проверяет архивы и отказывается восстанавливать данные
  поверх существующих пользовательских объектов.
- Временный контейнер и временные дампы внутри рабочего PostgreSQL удалены.
- Все семь рабочих контейнеров продолжили работу; рабочие базы, тома, схема,
  API-контракт и код приложения не изменялись.

Для восстановления после удаления томов сначала запускаются только PostgreSQL
и Redis, затем комплектный `Restore-Databases.ps1`, затем остальное приложение
через Compose. Если прежний PostgreSQL-том сохранился, восстановление поверх
заполненных баз не требуется. `migrate:fresh` и повторное заполнение через seed
для восстановления не используются.
