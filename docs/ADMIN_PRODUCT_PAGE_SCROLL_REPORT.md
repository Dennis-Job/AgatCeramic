# Единая вертикальная прокрутка товаров — 2026-10-02

## Результат

На `/products` вертикально прокручивается весь документ. Таблица больше не
ограничена высотой viewport и не создаёт дополнительную вертикальную полосу.
Её оригинальная шапка движется вместе со страницей до нижней границы меню,
после чего закрепляется под ним. У нижнего края таблицы закрепление заканчивается;
при возврате вверх заголовки возвращаются на исходное место.

`UiTable` поддерживает opt-in `stickyHeader="page"`. Этот режим включён только
для товаров; остальные таблицы сохраняют прежний локальный scroll.
Горизонтальная прокрутка и крайние колонки от 1280 px сохранены. Шапка не
клонируется: кнопки сортировки, `aria-sort` и семантика таблицы остаются оригинальными.

Из-за CSS overflow-x контейнера обычный вертикальный sticky привязался бы к
контейнеру таблицы. Поэтому оригинальный `thead` перемещается внутри него
согласно геометрии документа. Верхняя граница задана общим `--admin-shell-height`.
Scroll/resize обработчики объединяют обновления через requestAnimationFrame;
ResizeObserver учитывает изменение размеров таблицы. Все ресурсы очищаются
при размонтировании и смене режима.
