# Прогресс обработки объединений

Дата: 2026-10-07.

## Причина

После успешной загрузки исходного файла операция №11 имела
`status=completed`, `total_rows=3`, `processed_rows=1`, `created_rows=1`,
`updated_rows=0`, `failed_rows=0`. Поэтому Admin показывал «1 из 3» и 33%.
Группа `1234567` «Раковины цвета» действительно создана; проверен состав
SKU `6000030`–`6000033`.

Reader считает три строки групп, включая две «Не изменять», а service
создаёт одно атомарное задание для всех изменений файла. Счётчик ошибочно
увеличивался на количество заданий, не на количество обработанных групп.

## Исправление

Инициализация учитывает строки без действий как обработанные. Если файл
отклонён по ошибкам строк, все прочитанные строки считаются проверенными.
Завершение применения всего файла устанавливает `processed_rows=total_rows`.
Ошибка применения также завершает проверку файла целиком; счётчики ошибок
и фактически созданных/изменённых групп сохраняют отдельный смысл.

Frontend вычисляет процент из API как раньше. Разметка, стили и компоненты
не менялись; UI Design Guard не требуется для backend-only изменения
по `docs/UI_DESIGN_REVIEW.md`. API endpoints и структура ответа сохраняются;
семантика счётчика уточнена в `API.md` и OpenAPI. Миграций нет.

У завершённой операции №11 исправлен только технический `processed_rows`
с 1 на 3, с предварительной проверкой ID, статуса и исходных счётчиков.
API Resource подтверждает `completed`, `total_rows=3`, `processed_rows=3`,
`created_rows=1`, `updated_rows=0`, `failed_rows=0`. Каталог повторно не
обрабатывался. Worker перезапущен для следующих загрузок.

  только «Не изменять», две неизменяемые группы и одна новая, ошибка со
  строкой «Не изменять».
- После исправления профильный SQLite-прогон: 7 tests, 42 assertions passed.
- Изолированный PostgreSQL: 7 tests, 42 assertions passed; guard подтвердил
  `agatceramic_feature_test` перед запуском.
- Полный `composer test`: 372 tests, 5114 assertions passed.
- Pint, PHPStan, architecture guard, Composer validate/audit passed.
- OpenAPI lint/conventions и 42 OpenAPI tests passed; структура API не менялась.
- Проверяется повторный job: счётчик не растёт, новая группа не дублируется.
- Независимое code review: блокирующих замечаний нет.
