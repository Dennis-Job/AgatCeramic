# AgatCeramic

Интернет-магазин керамической плитки, мозаики, керамогранита, сопутствующих материалов и сантехники.

## Архитектура

```text
AgatCeramic
├── backend/             Laravel API-only
├── frontend/
│   ├── admin/           Vue 3 + TypeScript + TailAdmin-style PIM/CRM
│   └── client/          Nuxt.js SEO-first storefront
├── docs/                Проектная документация
├── tasks/               Задачи разработки
└── infrastructure/      Docker/CI/CD/deployment
```

## Принцип

Laravel — API и бизнес-ядро.

Vue Admin — интерфейс управления.

Nuxt Client — публичный интернет-магазин.

Не использовать Blade для визуального интерфейса.

## Клиентский сценарий

Регистрация клиента отсутствует.

Клиент:
- открывает каталог;
- выбирает категорию;
- выбирает товар;
- добавляет товар в корзину;
- оформляет заказ;
- указывает ФИО, телефон, адрес доставки и комментарий;
- получает email с номером заказа.

Онлайн-оплаты нет.

После получения заказа менеджер связывается с клиентом.

## Административный сценарий

Сотрудник входит в админ-панель.

Доступ зависит от роли и permissions.

Администратор управляет:
- каталогом;
- товарами;
- вариантами товаров;
- категориями;
- характеристиками;
- брендами;
- заказами;
- обращениями;
- продажами;
- контентом;
- SEO;
- настройками;
- магазинами;
- пользователями и правами.
