# START HERE — AgatCeramic

Этот файл предназначен для первого запуска работы в Codex.

## Первый запрос

Прочитай:
- `/AGENTS.md`
- `/README.md`
- `/docs/REQUIREMENTS.md`
- `/docs/ARCHITECTURE.md`
- `/docs/DATABASE.md`
- `/docs/API.md`
- `/docs/DECISIONS.md`
- `/tasks/TODO.md`

После изучения НЕ начинай сразу писать бизнес-функциональность.

Сначала:
1. Проверь текущую структуру проекта.
2. Проверь Git.
3. Проверь установленные версии PHP, Composer, Node.js, npm/pnpm и Docker.
4. Составь план TASK-001...TASK-007.
5. Найди противоречия или недостающие решения.
6. Предложи минимальный набор решений для старта.
7. Не устанавливай лишние зависимости без объяснения.

После этого жди подтверждения пользователя перед выполнением Phase 0.

## Правило дальнейшей работы

Каждая задача выполняется отдельно.

Формат запроса:

"Реализуй TASK-XXX из tasks/TODO.md.

Перед началом изучи AGENTS.md и релевантную документацию.
Сначала покажи краткий план.
Не меняй несвязанные части проекта.
После реализации запусти тесты/checks.
Обнови статус задачи и документацию, если это необходимо."
