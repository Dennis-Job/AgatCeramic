# AgatCeramic Client

Nuxt 4 storefront with SSR enabled by default. This project is the public, SEO-first frontend; business data is supplied exclusively by the Laravel API.

## Local commands

```powershell
npm install
npm run dev -- --host 127.0.0.1
npm run build
```

The initial scaffold contains only the Nuxt application shell and a neutral page. Catalog, cart, checkout, SEO entities, structured data, sitemap, robots, and visual design are implemented in their dedicated tasks.

## Runtime compatibility

The scaffold uses Nuxt 4.5.2. It requires Node 22.19+, Node 24.11+, or Node 26+; the supported Node version must be used in development, CI, and production.
